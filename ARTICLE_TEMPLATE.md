# Article template

Copy this structure into a new file under `content/drafts/` (and later `content/ready-for-review/`).  
File name: `YYYYMMDD-short-slug.md` (slug is working, not necessarily final).

Fill from **research notes only**. Empty required fields are better than invented ones. Use `[NEED SOURCE]` or move the task to `BLOCKED`.

Do not use this template during discovery. Discovery uses state records only.

---

```markdown
# [Working / proposed headline]

## Packet metadata

| Field | Value |
| --- | --- |
| Task ID | |
| State | DRAFTING / BLOCKED / READY_FOR_REVIEW |
| Research date | YYYY-MM-DD |
| Last updated | YYYY-MM-DD |
| Authoring agent / human | |
| Primary beat | |
| Secondary beat (optional) | |

## Proposed headline

(Publish-facing; must be supportable. No fake urgency.)

## Story type

News | Analysis | Explainer | Feature | List/guide | Opinion  
(If mixed, name dominant type and describe the mix.)

## Target audience

Who this is for, including any specific diaspora/geography/language community. Do not write “everyone.”

## Why now

What changed, or why this durable story is being told on this date. No invented pegs.

## Central angle

One or two sentences: the idea the piece defends or reveals. Not a topic label.

## Primary sources

For each: name/title, URL or location, date, what it establishes, retrieval date.

## Secondary sources

For each: publication, byline if any, URL, date, what we take from it (attributed in draft).

## Reporting / research notes

- What was searched
- What could not be verified
- Interviews: none unless they actually occurred (do not invent outreach)
- Safety or sensitivity flags
- Distinctions among communities that the draft must preserve

## Outline

1. …
2. …

## Full draft

(Article body. Subheads as needed. Attribution in prose. No fabricated quotes.)

## Facts requiring final verification

Checklist of load-bearing facts (names, dates, numbers, titles, quotes) still needing a human or a second source.

## SEO title

(May differ slightly from headline; no keyword stuffing; no unsupportable claims.)

## Meta description

~140–160 characters, accurate, not clickbait.

## Slug

lowercase-hyphenated, stable if possible.

## Excerpt

1–3 sentences for the site listing; must match the draft.

## Category

One primary category consistent with editorial areas.

## Tags

Specific, not generic spam. Prefer named people, works, places, languages.

## Internal-link opportunities

Existing or likely brwncltr URLs/topics—**do not invent published URLs**. If archive is unknown, list *themes* and mark `[ARCHIVE UNKNOWN]`.

## Social captions

- Instagram/feed
- X/Twitter-length
- Optional: newsletter blurb  

Still no invented facts. Do not imply a scoop we do not have.

## Featured-image concept

Description for a human/designer: subject, mood, what not to stereotype. No stolen-image instructions. Credit/licensing to be handled by humans.

## Research date

YYYY-MM-DD (when sources were last checked).
```

---

## Completeness gate (before `READY_FOR_REVIEW`)

A packet may move to `content/ready-for-review/` only when:

- Story type, angle, why now, and audience are filled
- Primary/secondary sources are listed (or `BLOCKED` explains the gap)
- Full draft exists **or** the state is `BLOCKED` with a partial draft and a stop reason
- Facts-requiring-verification is honest (empty only if everything is checked)
- SEO/slug/excerpt/category do not introduce new unsourced claims
- No quotes or statistics without sources
